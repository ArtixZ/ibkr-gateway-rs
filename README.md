# gatewayctl

**Independent IB Gateway supervision for macOS**

Rust supervisor | Java agent | MIT licensed

</div>

Run paper and live IB Gateways side by side with isolated settings, Keychain
credentials, and session-preserving native restarts.

**The implementation and setup guide are being introduced through the
[initial pull request](https://github.com/ArtixZ/ibkr-gateway-rs/pulls).**
This default branch currently contains the project introduction and license.

> **Unofficial and experimental.** Not affiliated with Interactive Brokers or
> IBC. Test with paper trading first. Live API clients can trade real money,
> and broker-required MFA still needs user approval.
